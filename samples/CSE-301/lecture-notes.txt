Lecture 5: Binary Search Trees
A binary search tree (BST) is a binary tree where, for each node, all keys in the left subtree are smaller and all keys in the right subtree are larger. Search, insert and delete take O(h) time where h is the height. An inorder traversal of a BST visits keys in sorted order.
Deletion has three cases: a leaf is removed directly; a node with one child is replaced by its child; a node with two children is replaced by its inorder successor (the minimum of the right subtree), which is then deleted.Lecture 6: AVL Trees
An AVL tree is a self-balancing BST where the heights of the two child subtrees of any node differ by at most one (the balance factor is -1, 0 or +1). After an insertion the tree is rebalanced with rotations: LL imbalance uses a right rotation, RR uses a left rotation, LR uses a left then right rotation, and RL uses a right then left rotation. The height of an AVL tree with n nodes is O(log n), so all operations are O(log n).Lecture 7: Heaps and Priority Queues
A binary heap is a complete binary tree stored in an array. In a max-heap every parent is greater than or equal to its children. Insert adds at the end and sifts up in O(log n). Extract-max swaps the root with the last element and sifts down in O(log n). Building a heap from n elements takes O(n). Heap sort builds a max-heap then repeatedly extracts the maximum, giving O(n log n) time.
A priority queue is an abstract data type supporting insert and extract-max (or min); heaps implement it efficiently.Lecture 9: Shortest Paths
Dijkstra's algorithm finds shortest paths from a single source in a graph with non-negative edge weights. It keeps a distance table initialised to infinity (0 for the source) and repeatedly selects the unvisited vertex with the smallest distance, relaxing its outgoing edges. With a binary heap it runs in O((V + E) log V). Dijkstra's algorithm fails with negative edge weights; Bellman-Ford handles those.
